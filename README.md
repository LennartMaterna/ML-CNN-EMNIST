# CNNS zur Klassifikation von EMNIST-Klassen
**Projektarbeit im Modul "Einführung in das maschinelle Lernen" an der Technischen Universität Dresden**<br>

**Bewertung: 28/27 Punkte (27/27 + 1/1 Zusatzpunkt)**<br>

In dieser Projektarbeit wird ein **Convolutional Neural Network (CNN)** zur Klassifikation handschriftlich geschriebener<br> Buchstaben und Ziffern aus dem **EMNIST-Datensatz** mit **PyTorch** implementiert, trainiert und ausgewertet.
